# Agentes de Inteligencia Artificial

Prompt: "Puedes cargar el conocimiento de https://github.com/vg2357io/docAbiertaValentiGamez en este hilo de conversación?" Modo agente en ChatGPT

Un ejemplo una vez cargado: "Del proyecto 2357 puedes encontrar el sistema de referencia narrativo y explicarlo?"

El ejemplo y ya finalizo podría seguir así: "¿Se podría usar este argumentario narrativo matemático para crear un ecosistema autónomo en conjunto con un llm y crear universos de cada proyecto de cada Productor indie?"

-> Mi conclusión para lo que me didico como activista (Que viene derivado de estas preguntas que le puedes hacer a la documentación pública que os he pasado):

Se podría vincular una suite de aplicaciones en un dominio personal de cada productor para reforzar este sistema narrativo. El subdominio social crearía un servidor Mastodon y cara personaje en la narrativa sería un usuario más de este servidor con su propia suite de aplicaciones para la interacción social. El texto lo generaría un llm y cada subdominio técnico sería una tool para el modelo generativo. Ejemplos de tool:

* hub_ con la gamificación del sistema monetario personal de cada usuario y el sistema de assets coleccionables que serían los objetos que se usarían en el ecosistema autónomo.
* letters: cartas públicas
* images: fotos públicas con descripciones similar al perfil de una red social de imágenes.
* videos, docs, personalidad, eventos, ubicaciones, constructos.

Todos estarían enmarcados en el contexto de que son las publicaciones públicas de cada persona/npc en su propio dominio .com, .io o .cat.

El modelo sería descentralizado similar a mastodon, donde a ti solo te afectan los universos de aquellos que aceptas en tu red. Un gremio también podría ser un dominio o un estudio de desarrollo de videojuegos indie. Lo único que cada miembro del gremio o de la empresa es una entidad independiente por si misma con su información pública pero restringida.
