# Agentes de Inteligencia Artificial

Un ejemplo una vez cargado: "Del proyecto 2357 puedes encontrar el sistema de referencia narrativo y explicarlo?"

El ejemplo y ya finalizo podría seguir así: "¿Se podría usar este argumentario narrativo matemático para crear un ecosistema autónomo en conjunto con un llm y crear universos de cada proyecto de cada Productor indie?"

-> Mi conclusión respecto a mi labor como activista (derivada de las preguntas que pueden plantearse a la documentación pública que os he compartido):

Podría vincularse una suite de aplicaciones al dominio personal de cada productor para reforzar este sistema narrativo. El subdominio social alojaría un servidor Mastodon, y cada personaje de la narrativa sería un usuario más dentro de ese servidor, con su propia suite de aplicaciones para la interacción social.

El contenido textual sería generado por un LLM, y cada subdominio técnico funcionaría como una tool del modelo generativo. Ejemplos de tools:

* hub: gamificación del sistema monetario personal de cada usuario y gestión de assets coleccionables, que actuarían como los objetos utilizados dentro del ecosistema autónomo.

* letters: cartas públicas.

* images: imágenes públicas con descripciones, de forma similar a una red social visual.

* videos, docs, personalidad, eventos, ubicaciones, constructos.

Todo este conjunto se enmarcaría como publicaciones públicas de cada persona o NPC en su propio dominio (.com, .io, .cat, etc.).

El modelo sería descentralizado, similar a Mastodon, donde únicamente te afectan los universos de aquellos a quienes aceptas en tu red. Un gremio también podría constituirse como un dominio propio, al igual que un estudio de desarrollo de videojuegos indie. La clave es que cada miembro del gremio o de la empresa sea una entidad independiente en sí misma, con información pública propia, aunque con acceso y visibilidad restringidos según el contexto.
