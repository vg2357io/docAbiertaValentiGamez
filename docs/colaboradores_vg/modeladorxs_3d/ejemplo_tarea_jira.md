# [Asset] Calendario de Adviento Navideño

Se requiere el modelado de un **Calendario de Adviento Low Poly**, diseñado para la integración en la escena temática navideña. Este asset debe ser estructuralmente modular para permitir la apertura o el cambio de estado de sus 4 (2, 3, 5 y 7) puertas/compartimentos (En lugar de las 24 habituales) en Godot. El calendario debe tener 2 puertas/compartimentos ocultos (Al revelarse son “i” y “o”), deben poder abrirse pero deben estar comuflados.

* **Seguir la documentación para modeladorxs3d**: https://docs.valentigamez.com/#/colaboradores_vg/modeladorxs_3d/README 

* **Estilo Visual**: El asset debe coincidir con el estilo Low Poly de color plano limpio (clean flat color style) del kit Holiday de Kenney. Los ejemplos incluyen el reno, la caja de regalo, y las coronas. Puedes descargar el kit de assets desde el siguiente enlace: https://kenney.nl/assets/holiday-kit 

* **Referencia**: https://drive.google.com/drive/folders/1CiqHesZQv8sHJRFt_wGCj63cecvjX3yU?usp=drive_link 

* **Ruta en Google Drive**: Diseño/Assets3D/kit_navidad/calendario_adviento

El modelador debe cumplir con la siguiente lista de verificación antes de mover la tarea a la columna "En Revisión":

[ ] El asset está modelado con la menor cantidad de polígonos posible (Low Poly).

[ ] El asset utiliza el Atlas de Color y tiene un solo material.

[ ] El objeto en Blender ha sido renombrado con la nomenclatura estándar (prop_holiday_advent_calendar_01).

[ ] El punto de pivote (Object Origin) está en la base (Z=0) y alineado a la rejilla.

[ ] Se han eliminado caras internas u ocultas.

[ ] Se han aplicado la escala y rotación (All Transforms applied).

[ ] Se ha exportado el archivo final .glb.

[ ] Se ha realizado una validación básica importando el .glb en Godot para verificar la escala y el snapping.

[ ] Se ha creado el Pull Request (PR) en Bitbucket, incluyendo el identificador de Jira en el título.

[ ] La rama de Bitbucket lleva el código de Jira.

[ ] Se ha subido el asset a Google Drive (El .blend y .glb).
