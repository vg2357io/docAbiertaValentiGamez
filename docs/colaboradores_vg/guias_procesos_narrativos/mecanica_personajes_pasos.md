# Guía rápida de asignación mecánica

## 1. Atributos base

Asigna primero el **nivel del ser** y no pienses más de la cuenta.

**Rangos orientativos:**

* **Humano / criatura común**

  * Nivel: **23–75**
  * Pico alto en algo concreto: **123–235**

* **Héroe destacado / élite**

  * Nivel: **75–123**
  * Especialidad clara: **235**

* **Deidad**

  * Nivel: **235–753**
  * Aspectos clave: hasta **2357**

* **Primigenio**

  * Nivel: **2 o 2357** Dormido o no.
  * Núcleo del ser: puede llegar a **235710**

**Reglas rápidas:**

* No usa magia → `AP = 2`, `MR = 2`
* Mundo con magia → `AP y MR ≥ 5`

## 2. Afinidades de acciones y habilidades

Solo define **2, 3, 5 o 7 habilidades** importantes. El resto van por cono.

### Escala rápida de afinidad (0–2357)

* **23** → Apenas sabe hacerlo (muy raro que salga bien o muy torpe)
* **80–120** → Aficionado / básico
* **235** → Competente estándar
* **400–800** → Muy bueno
* **1000–2357** → Maestro / rasgo definitorio

> Si dudas entre dos números, usa **235**. Es el valor neutro del sistema.

## 3. Cono de habilidades (sin números)

Para cualquier acción **no definida**, colócala mentalmente en el cono:

* **Núcleo**

  * Acciones automáticas, instintivas, identitarias
  * Usa afinidades **altas** (≈ 235 o más)

* **Zona cercana**

  * Acciones habituales, entrenadas
  * Usa afinidades **medias** (≈ 120–235)

* **Zona media**

  * Acciones posibles pero incómodas
  * Usa afinidades **bajas** (≈ 23–80)

* **Periferia**

  * Acciones forzadas, raras, impropias
  * Usa afinidades **mínimas** (≈ 23 o menos narrativamente)

No se recalcula nada. **Decisión instantánea y a jugar**.

## 4. Aptitudes

Determina entre 2 y 235 las aptitudes:

* AD → (Ataque físico)
* DEF → (Defensa física)
* AP → (Ataque mágico)
* MR → (Defensa mágica)

Determina si tus acciones hablidades escogidas son físicas, mágicas o cuánticas.

* **Física**
* **Mágica**
* **Cuánticas** → Mentales → (**Física** + **Mágica**) / 2

Determina tu afinidad final en tus acciones y habilidades: `afinidad` + `aptitud asociada`

Determina el multiplicador cónico de tus acciones y habilidades: `afinidad final / 2357`

## 5. Resultado de la acción (ultra rápido)

1. Multiplicador cónico
2. × **3** (o dado de 6 si hay azar)
3. Redondea hacia arriba

### Interpretación directa

* **0** → Fracaso
* **1** → Determinado por narrativa
* **2** → Éxito
* **3** → Éxito crítico
* **5** → Éxito sintónico (encaja perfecto)
* **7** → Éxito natural (inevitable)

## 6. Regla de oro del sistema

> **Si el número interrumpe la historia, el número está mal elegido.**
> El sistema existe para sostener la narrativa, no para competir con ella.
