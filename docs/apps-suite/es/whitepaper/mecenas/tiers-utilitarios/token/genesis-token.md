# Genesis Token

## Principios de génesis

- Objetivo: arrancar un ecosistema de uso (no de inversión) con asignaciones iniciales claras y verificables.
- Suministro inicial: definido y publicado; sin acuñaciones discrecionales.
- Desbloqueos: calendarios simples y públicos, ligados a hitos de entrega.

## Asignaciones sugeridas (referenciales)

- Comunidad y contribuciones: X% con vesting por hitos.
- Ecosistema/partners: Y% con cláusulas de uso específico.
- Tesorería operativa: Z% con controles de firma múltiple.

## Métricas de arranque

- Número de usuarios activos con utilidades reales.
- Uso de funcionalidades gated por token (si aplica).
- Participación en programas de contribución.
