# Distribución de Tokens

## Criterios de distribución

- Orientada a uso y contribución verificable.
- Transparente y sencilla de entender.
- Evitar concentraciones que puedan distorsionar la gobernanza.

## Esquema referencial

- Comunidad/contribuciones: 40–60% (vesting por hitos).
- Ecosistema/partners: 10–20% (acuerdos de colaboración técnica).
- Tesorería operativa: 15–25% (gastos de infra/compliance).
- Reserva para incentivos educativos: 5–10%.

## Desbloqueos

- Lineales o por entregables (ADRs, módulos, releases etiquetadas).
- Calendario público y automatizado cuando sea posible.
